# WindowsPostInstallationTool

## Что это?

* Это скрипт для быстрой установки распространенного ПО использующий Microsoft WinGet встроенный в ОС Windows по умолчанию, которая обычно не требует участия пользователя, либо максимум запросит повышение привилегий в зависимости от разработчика устанавливаемого ПО

## Системные требования

* ОС Windows 10/11 с последними обновлениями, содержащими WinGet в комплекте (обычно достаточно просто обновить Windows)
* Доступ в интернет (от 50 на пакет в зависимости от веса выбранного ПО)
* Прямые руки (но не обязательно)

## Для чего оно?

* Я хотел быстро ставить большое количество программ чтобы не ходить по сайтам и не искать каждый раз. Пришла идея сделать этот скрипт и теперь Вы можете просто выбрать программу из списка и ввести ее номер для установки.
* Скрипт многоразовый, его не нужно каждый раз перезапускать. Просто дождитесь окончания установки и нажмите ENTER

## Тут нет нужной мне программы!

* Создайте Issue с просьбой добавить то или иное ПО. Я рассмотрю Вашу просьбу и программа появится в приложении, если конечно ее пакет есть в WinGet

## Планы на развитие

* Я планирую добавить больше приложений и скриптов для упрощения процедур установки, а если скрипт воспользуется популярностью, то я напишу полноценное ПО в котором будет автоматизация установки сразу нескольких программ подряд.
* Со временем рассмотрю возможность запуска этого скрипта по сети без необходимости предварительного скачивания
